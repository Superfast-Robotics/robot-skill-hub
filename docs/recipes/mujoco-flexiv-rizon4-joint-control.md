# flexiv rizon4 joint-position control

flexiv rizon4 joint-position control. Bounded simulated joint offsets from the original reset pose; not locomotion or object-task validation.

Move the named actuated hinge joints by a bounded offset from the reset/settled pose; max residual <0.035 rad and nonzero actual motion. This is not end-effector planning, balance, locomotion or hardware control.
