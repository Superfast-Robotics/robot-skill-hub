# Unitree Go2 torque-limited standing control

Unitree Go2 torque-limited standing control. Bounded, source-pinned simulation; no hardware execution.

Maintain standing for 3500 native simulation steps using bounded joint PD torques, including reset-time base-velocity perturbations. Upright/height/tracking postconditions are required. No gait or locomotion capability is asserted.
