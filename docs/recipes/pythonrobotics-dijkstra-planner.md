# Dijkstra collision-checked grid path

Parameterized adaptation of `PathPlanning/Dijkstra/dijkstra.py` from https://github.com/AtsushiSakai/PythonRobotics at `cdd0cc888802b584c2d654ca85e3c5460973487d`. Original authors: Atsushi Sakai and PythonRobotics contributors. Upstream license: MIT. Source license and all notices remain in the prepared checkout; the Hub adapter is MIT.

Use the record interface for input/output schemas, units, frames, prerequisites and failures. `--describe` reads the contract; `--example` runs the declared case. Replace `--example` with `--input TASK.json` for a different input. This adapter does not command physical hardware.
