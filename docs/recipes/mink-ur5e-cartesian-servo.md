# Mink ur5e differential IK and actuator servo

Mink ur5e differential IK and actuator servo. Bounded, source-pinned simulation with an explicit task contract and retained fixed-case outcomes.

Differential IK with configuration limits, followed by 3000 MuJoCo dynamics steps using position actuators; final position error below 15 mm and orientation error below 0.05 rad. No qpos teleport after reset.
