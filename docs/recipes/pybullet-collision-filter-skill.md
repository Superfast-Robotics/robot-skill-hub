# Collision filtering in headless procedural simulation

Parameterized adaptation of `examples/pybullet/examples/collisionFilter.py` from https://github.com/bulletphysics/bullet3 at `2c204c49e56ed15ec5fcfa71d199ab6d6570b3f5`. Original authors: Erwin Coumans and Bullet Physics contributors. Upstream license: Zlib. Source license and all notices remain in the prepared checkout; the Hub adapter is MIT.

Use the record interface for input/output schemas, units, frames, prerequisites and failures. `--describe` reads the contract; `--example` runs the declared case. Replace `--example` with `--input TASK.json` for a different input. This adapter does not command physical hardware.
