# Minimum-duration jerk-limited trajectory

Parameterized adaptation of `examples/07_minimum_duration.py` from https://github.com/pantor/ruckig at `a8db97a4e9c55e5160a3855f739fa3b270df8e4c`. Original authors: Lars Berscheid and Ruckig contributors. Upstream license: MIT. Source license and all notices remain in the prepared checkout; the Hub adapter is MIT.

Use the record interface for input/output schemas, units, frames, prerequisites and failures. `--describe` reads the contract; `--example` runs the declared case. Replace `--example` with `--input TASK.json` for a different input. This adapter does not command physical hardware.
