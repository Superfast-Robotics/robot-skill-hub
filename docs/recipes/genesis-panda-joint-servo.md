# Genesis Panda joint-servo

Genesis Panda joint-servo. Bounded, source-pinned simulation with an explicit task contract and retained fixed-case outcomes.

CUDA dynamic simulation after reset. PD tracking below 0.04 rad and nontrivial hand motion; IK variant also requires final hand position error below 15 mm. Source example kinematic visualization is adapted to real simulation stepping.
