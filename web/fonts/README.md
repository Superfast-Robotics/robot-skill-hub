# Brand fonts

Self-hosted, unmodified font files from the official Google Fonts repository:

- Schibsted Grotesk variable upright: https://github.com/google/fonts/tree/main/ofl/schibstedgrotesk
- IBM Plex Mono Regular: https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Both are distributed under the SIL Open Font License 1.1. See the accompanying `*-OFL.txt` files. Fonts are loaded from this site's own assets; no third-party font service is contacted.
